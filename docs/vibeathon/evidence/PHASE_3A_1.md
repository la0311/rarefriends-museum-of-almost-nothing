# Phase 3A.1 — G1 frame-fit hotfix

Owner playtest found desktop Expedition terms overflow and 360px actions clipped below the game frame. Measured before editing: the desktop child was 958 × 638 with the runtime toolbar beginning at host y=589; reveal content reached child y=619, and curation content reached y=597. The 360px host was 360 × 240, child 358 × 238, with toolbar beginning at host y=197. Header and room alone reached child y=321; curation controls ended far below the frame. Fixed room height, mobile padding and normal-flow terms caused the overflow. The prior test succeeded because Playwright scrolled off-screen buttons into view.

The patch preserves the 960 × 640 desktop host and gives widths up to 500px a supported 3:4 host aspect ratio through `host.css`. Child layout now uses the measured viewport height, lets the room absorb available space, reserves the bottom runtime toolbar band, and keeps contextual actions above it. Expedition terms are in a contained keyboard/touch dialog with Close and Escape; game actions are disabled while it is open. No economy schema or state-machine changes were made.

Validation: `npm run typecheck`, `npm run check`, `npm run build`, and `node tests/museum.mjs` passed. The focused browser test runs the full G1 loop at 960px and 360px and now checks each relevant state for required element bounds, zero child document scrolling, museum content inside the room, and controls above the trusted runtime toolbar. It also checks terms before purchase and pause protection. Screenshots: `g1-hotfix-curation-960.png`, `g1-hotfix-present-960.png`, `g1-hotfix-curation-360.png`, `g1-hotfix-present-360.png`, and `g1-hotfix-terms-360.png`.

The hotfix was published to GitHub Pages as `de7e3b3a1515a20f349ebb8ddd3edbed07a44084`. GitHub Pages reports built. Clean public browser checks loaded HTTPS with the SDK wallet gate and no asset/browser errors at 960px and 360px; measured host frames are 960 × 640 and 360 × 480. Real eligible-wallet gameplay remains unverified until the owner recheck.
